# 企业级 RAG 知识库平台 · 真实项目版

本机可运行的全栈版本：真实文件上传、真实切片与检索、真实评测记录，RAG 能力对接 **Dify**（未配置时自动使用本地引擎，保证全流程可用）。

> 边界声明：企业与业务数据为虚拟案例；本版本用于本地验证与作品演示，未在真实企业上线，不代表生产 SLA。

## 如何打开（重要）

**这是一个 Web 应用，不能直接双击 `web/index.html`。** 必须启动本地服务：

1. 双击 **`start.cmd`**（或项目根目录的 `打开真实项目版.cmd`）；
2. 等待窗口提示启动成功，浏览器会自动打开 <http://127.0.0.1:8787>；
3. **保持该窗口开启**；关闭窗口即停止服务。

如果双击 `web/index.html`，页面会显示提示并阻止继续加载（浏览器禁止 file:// 下调用本地 API）。

若窗口闪退，请在该目录打开命令行执行 `npm start`，把报错信息发给维护者；最常见原因是未安装 Node.js 22.5+。

## 配置 Dify（可选，推荐）

1. 打开 Dify（Cloud 或自建）→ 知识库 → API → 创建一个**数据集 API Key**（用于建 dataset、上传文档、查询切片、检索）；
2. 准备一个**生成应用 Key**，二选一：
   - 文本生成应用（Completion）：提示词使用变量 `{{query}}` 与 `{{context}}`；
   - 聊天 / 高级聊天应用（Chat）：平台会把检索资料拼进提示词，要求模型仅依据资料回答（已验证可用的回退模式）。
3. 填写 `.env`：

```ini
DIFY_BASE_URL=https://api.dify.ai/v1
DIFY_DATASET_KEY=dataset-xxxx
DIFY_COMPLETION_KEY=app-xxxx
```

也可以在页面「RAG引擎配置」中填写（保存到本机 settings 表）。

**降级与混合模式**：

| 配置情况 | 检索 | 回答生成 |
|---|---|---|
| 数据集 Key + 生成 Key | Dify 数据集检索 | Dify LLM |
| 仅生成 Key | 本地 BM25 | Dify LLM（混合模式） |
| 都没有 | 本地 BM25 | 抽取式回答 |

未配置数据集 Key 时，入库与检索使用本地引擎，但平台全部流程仍可完整运行。

> 真实评测会调用 embedding 与生成接口，200 条回归会产生 token 费用。页面提供「使用 Dify 生成」开关：实测 5 条冒烟用 LLM 约 35 秒，关闭后约 1 秒；全量回归建议关闭 LLM 快速验收，再对重点问题抽样开启。

**限流与降级**：Dify Cloud 免费/沙盒订阅对知识库 API 有请求频率限制。平台在遇到 403/429 限流时会自动指数退避重试；仍失败则本次检索降级为本地 BM25，知识库入库与生成不受影响。评测前会自动把知识库中「已发布但尚未同步」的文档补传到测试 dataset（`syncPublishedDocs`），保证历史知识参与回归。配置 Dify 时评测串行执行，避免触发限流。

## 功能范围（F-01~F-10）

- 知识库管理：创建/编辑/归档；首次推送时自动在 Dify 创建测试与生产两个 dataset。
- 文档与版本：真实文件落盘（`data/uploads`）、元数据、版本记录、状态机。
- 业务审核：三项确认 + 备注；驳回原因必填；通过后自动创建测试入库任务。
- 入库任务：Dify 上传与索引状态轮询；失败重试；处理进度真实回写。
- 处理结果验收：读取 Dify segments（或本地切片）作为真实结果；五项检查。
- 检索调试：Dify retrieve / 本地 BM25；真实相关度；确认通过或标记问题。
- 批量评测与发布：冒烟 5 / 正式 40 / 全量回归 200；问题案例阻断；客服对话验收登记；审批发布写入生产 dataset。
- 问题案例：三来源、只读证据、source_key 去重、标记已处理。
- 权限与审计：登录会话、五角色 RBAC、审计日志、平台 API Key 掩码管理。
- 运营统计：文档、发布、评测与问题案例统计。

## 已知边界

- 单租户、本地账号，未接入企业 SSO；
- 客服对话验收由人工在外部聊天窗完成后登记，平台不内嵌聊天；
- 生产发布只做数据集写入与状态登记，不含灰度、监控与回滚编排；
- 本地引擎为关键词检索 + 抽取式回答，语义能力弱于 Dify embedding 检索。

## 安全说明

- 密钥仅保存在 `.env` 或本机 SQLite，不出现在前端与日志；
- 会话 Cookie 为 HttpOnly；所有写接口做角色与状态校验；
- 上传文件类型白名单（PDF/DOCX/TXT/MD/CSV/HTML），上限 60MB。
