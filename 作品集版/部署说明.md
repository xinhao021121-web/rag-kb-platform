# 作品集版 · 部署说明

本目录是可直接上传到 Cloudflare Pages 的完整站点（原 `xinhao-portfolio.pages.dev` 的更新版）。

## 一、本次改动

1. **主项目替换**：首页 `index.html` 的「主项目 · 售后知识协作」整段已删除，替换为「企业级 RAG 知识库平台」（新流程图、双特性卡、结果指标与案例入口）。
2. **新增案例页**：`RAG知识库平台案例.html`（问题 / 方案 / 验证 / 判断 / 边界 / 联系），风格沿用线上页面的内联 CSS。
3. **新增原型**：`RAG知识库平台-交互原型.html`（单文件、模拟数据、双击即用），案例页与首页均有入口。
4. **原主项目彻底移除**：首页与页脚不再出现「售后知识协作」及 `项目案例.html` 链接；该案例页不包含在本部署包内（本地备份在 `D:\项目\学习\RAG管理平台\_归档_原主项目\`）。
5. **素材**：`assets/` 仅保留当前站点实际引用的图片，新增 `RAG-*.png` 截图。

## 三、部署到 Cloudflare Pages

### 方式 A：控制台拖拽（最快）

1. 打开 Cloudflare Dashboard → Workers & Pages → 你的 Pages 项目 → Create deployment / Upload assets。
2. 将 **`作品集版` 目录内的全部文件**（不是外层文件夹）拖入上传区。
3. 部署完成后访问 `https://xinhao-portfolio.pages.dev/` 验证。

### 方式 B：Git 仓库（如站点由仓库自动构建）

1. 用本目录内容覆盖仓库中原站点文件。
2. **删除仓库中的 `项目案例.html`**（本次要求彻底移除）。
3. 提交并推送，等待 Pages 自动构建。

### 上线后必须检查

- 首页主项目区已是「企业级 RAG 知识库平台」，不再出现「售后知识协作」。
- 首页两个「查看完整案例 / 阅读主项目」均跳转到 `RAG知识库平台案例.html`。
- 若线上仍存在 `项目案例.html`，请在 Pages 项目里删除该文件（本包已不包含）。
- 案例页「在线体验交互原型」能打开 `RAG知识库平台-交互原型.html`。
- 手机宽度（390px）下首页与案例页无横向滚动、无文字竖排。

## 四、本地预览

直接双击 `index.html` 即可浏览（所有页面使用相对路径与内联样式，无需服务器）。

案例页与原型均可离线打开；原型数据保存在浏览器 localStorage，侧边栏「↺ 重置演示数据」可恢复初始状态。

## 五、内容边界

- 交互原型使用**虚拟企业、模拟数据**，页面水印与文案已标注「虚拟案例 · 模拟数据」。
- 案例页明确区分「已经完成 / 尚未完成」，不宣称真实企业上线或真实业务指标。
- 真实全栈版本（Node + SQLite + Dify 接入）单独交付在 `真实项目版/`，不随本静态站点部署。
